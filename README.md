# 🍰 烤蛋糕小店（Cake Shop Rush）

基于 **React + HTML5 Canvas** 的 60 秒限时模拟经营小游戏：顾客探头点单，你负责烘烤、加料、制作冰激凌，在订单超时前交付蛋糕赚取分数。支持电脑与手机，**一屏内无需滚动**即可操作全部内容。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开提示的地址（默认 http://localhost:5173）
```

**或者直接玩构建产物**：`npm run build` 后，直接双击打开 `dist/index.html` 即可（已配置相对路径，无需服务器）。

## 玩法规则

1. **点单**：顾客探头点单，**前 20 秒最多同时 2 个订单，之后最多 3 个**；每个订单需要 1-3 个食物，订单时限 **15-40 秒随机**，超时离开（连击重置）。一局 60 秒。
2. **得分**：
   - 常规订单 **+10**；在时限过半前完成 **+15**
   - 急单 **+25**；盲盒订单随机 **5~20 分**
   - 连击（连续成功交单数）显示在顶部，超时重置，不直接影响得分
3. **盲盒订单**：15% 概率出现，只显示「？」盒子，**任意蛋糕或冰激凌**都能交付完成，随机得分 5~20。
4. **急单**：「⚡ 急单」**独立生成**——每个新订单有 **10% 概率直接是急单**，越到后期概率越高（最终约 30%）；急单**时间减半、完成后 +25 分**，已有订单**不会被转成急单**。
5. **烘烤**：点底部「蛋糕胚」放入烘烤机，5 秒烤好后 **8 秒内**点击烘烤机取出放到空盘子上；超时蛋糕会糊，需**双击烘烤机**清理。放入时有 **15% 概率触发「⚡ 加速烘烤」**（时间减半）。
6. **冰激凌**：点击冰激凌机制作，完成后点击交付给需要冰激凌的订单（盲盒也可）；没有订单需要时做好了不会坏，但不能放冰箱。制作完成时有 **10% 概率卡壳**，需再点一次继续。
7. **猫**：猫会随机靠近某个有蛋糕的盘子，**3 秒内点击赶走**，否则蛋糕被偷走。
8. **加料**：材料点击即放到盘中的蛋糕上（无限供应）：
   - 奶油百搭（围出底部明黄色花边）
   - 巧克力酱覆盖顶部，**不能与草莓/芒果同放**
   - 草莓、芒果放顶部中央，两者可叠加成「草莓+芒果」
   - 若目标蛋糕冲突，材料会自动放到其他不冲突的蛋糕上；都没有则点击无效
9. **交付**：点击有蛋糕的盘子——符合订单则交付并清盘；不符合则暂存到空冰箱（冰箱共 3 个，各存 1 个；全满则点击无效）。冰箱里的蛋糕符合订单时，点击冰箱即可交付。
10. **暂停**：随时可暂停，暂停后可继续或直接结算；结算页可「再来一局」或「返回主界面」。

## 文件结构

```
cake-game/
├── index.html            # 入口页面
├── vite.config.js        # Vite 配置（base: './' 便于直接打开 dist）
├── src/
│   ├── main.jsx          # React 挂载入口
│   ├── App.jsx           # 全部 UI 组件（开始/暂停/结算/游戏区/材料栏/订单栏/猫）
│   ├── game.js           # 游戏核心逻辑：常量、订单生成、状态 reducer（TICK + 玩家操作）
│   ├── draw.jsx          # Canvas 绘制：蛋糕/配料/冰激凌/顾客/盲盒/猫
│   └── style.css         # 样式（一屏布局 + 手机适配）
└── package.json
```

## 参数调整（src/game.js 顶部常量区）

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `GAME_DURATION` | 60 | 一局时长（秒） |
| `EARLY_PHASE` / `MAX_ORDERS_EARLY` / `MAX_ORDERS_LATE` | 20 / 2 / 3 | 前 20 秒最多 2 单，之后最多 3 单 |
| `BAKE_TIME` / `READY_WINDOW` | 5 / 8 | 烘烤时长 / 取出窗口（秒） |
| `ICE_CREAM_TIME` | 4 | 冰激凌制作时长（秒） |
| `ORDER_TIME_MIN` / `ORDER_TIME_MAX` | 15 / 40 | 订单时限随机范围（秒） |
| `SCORE_NORMAL` / `SCORE_FAST` / `SCORE_URGENT` | 10 / 15 / 25 | 常规 / 快速 / 急单得分 |
| `SCORE_TIMEOUT_PENALTY` | 5 | 常规订单超时扣分（急单超时不扣分） |
| `FAST_RATIO` | 0.5 | “半程”判定比例：完成时剩余时限 > total × FAST_RATIO 视为快速 |
| `BLIND_CHANCE` / `BLIND_SCORE_MIN` / `BLIND_SCORE_MAX` | 0.15 / 5 / 20 | 盲盒概率 / 盲盒得分范围 |
| `FAST_BAKE_CHANCE` | 0.15 | 加速烘烤概率 |
| `URGENT_BASE_CHANCE` / `URGENT_LATE_BONUS` | 0.1 / 0.2 | 急单生成概率 = 基础 + 进度 × 加成（不转化已有订单） |
| `ICM_STUCK_CHANCE` | 0.1 | 冰激凌机卡壳概率 |
| `CAT_CHANCE` / `CAT_CHECK_INTERVAL` / `CAT_DURATION` | 0.3 / 3 / 3 | 猫出现概率 / 检查间隔 / 徘徊时长 |
| `MAX_ORDERS`（旧） | — | 已被前/后期订单上限取代 |

想调整蛋糕样式组合，可修改 `CAKE_STYLES`；想调整订单里冰激凌出现概率，改 `generateOrder()` 里的 `Math.random() < 0.2`。
